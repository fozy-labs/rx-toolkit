# Формы

API форм нестабилен и экспортируется с префиксом `unstable_`; в примерах импорт алиасится
(`import { unstable_FormSignal as FormSignal }`). Определение — дерево `FormSignal.field` / `group` / `list`
со схемой Standard Schema у поля (здесь zod), инстанс — дерево узлов с `$`-сигналами, которые читаются
через `useSignal`. `api.defineForm` и `Definition.useForm` добавляет плагин `unstable_formsReactPlugin()`.
Документация — `docs/form/` в репозитории.
