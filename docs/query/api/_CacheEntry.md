# Запись кэша (CacheEntry) — API

Базовый реактивный контейнер, хранящий произвольное состояние `TState` с автоматической сборкой мусора (GC). Жизненным циклом записи управляет [удержание][cache-holds]: без удержаний запись «тает» и удаляется по `retentionTime`.

`TState` — это и то, что запись хранит, и то, что она публикует: [QueryCacheEntry][query-cache-entry-api] подставляет сюда плоскую запись [`TQueryEntryState<TArgs, TData>`][entry-state-concept].


## Опции

| Опция                | Тип                         | По умолчанию        | Описание                                                                                                |
|----------------------|-----------------------------|---------------------|---------------------------------------------------------------------------------------------------------|
| `initialState`       | `TState`                    | (Обязательное поле) | Начальное состояние. Устанавливается при создании записи.                                               |
| `retentionTime`      | `number \| false \| ((state: TState) => number \| false)` | (Обязательное поле) | Время (мс) удержания записи без удержаний. `false` — не удалять. Функция вызывается на каждом переходе `active → retention` (при создании записи — нет: запись, которую ни разу не удерживали, не удаляется) и получает состояние самой записи на этот момент; ловля броска, [нормализация результата][cache-normalize] и таймер — здесь же. См. [момент вычисления][cache-retention-moment]. |
| `devtoolsKey`        | `string`                    | (Обязательное поле) | Ключ для отображения в DevTools.                                                                        |
| `beforeDevtoolsPush` | `TBeforeDevtoolsPushFn<TState>` | —               | Перехватывает состояние перед отправкой в DevTools. Полезно для удаления чувствительных данных. |


## Свойства

| Свойство     | Тип                    | Описание                                                                     |
|--------------|------------------------|------------------------------------------------------------------------------|
| `state$`     | `ReadonlySignal<TState>` | Реактивный сигнал текущего состояния. Обновляется при каждом `set()`. Чтение в подписанном реактивном контексте удерживает запись; `state$.peek()` — нет. |
| `isMelting`  | `boolean`              | `true`, пока у записи нет удержаний. `isMelting === true` ⇔ состояние `retention` на [диаграмме записи][cache-lifecycle]; «тающая запись» в документации — то же самое. |
| `completed$` | `Subject<void>`        | Срабатывает один раз при удалении записи. Используется для очистки подписок. |


## Методы

| Метод      | Параметры      | Возвращаемое значение | Описание                                              |
|------------|----------------|-----------------------|-------------------------------------------------------|
| `hold`     | —              | `() => void`          | Удерживает запись без подписки на данные; возвращает идемпотентный release. На завершённой записи — no-op. |
| `peek`     | —              | `TState`              | Синхронный снимок состояния без реактивной подписки и без удержания. |
| `set`      | `state: TState`| `void`                | Обновляет состояние. Игнорируется после `complete()`. |
| `complete` | —              | `void`                | Завершает жизненный цикл.                             |
